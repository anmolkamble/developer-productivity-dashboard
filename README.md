Developer Productivity Dashboard
Overview

This project is a full-stack developer productivity dashboard that displays key engineering metrics and provides actionable insights. It focuses on helping developers understand performance trends and make better decisions instead of only showing raw data.

Features
Displays key metrics such as cycle time, deployment frequency, and bug rate
Provides insights explaining what each metric means
Suggests actionable improvements based on the data
Includes a visual productivity trend representation
Clean and responsive user interface
Tech Stack
Frontend: React (Vite)
Backend: Node.js with Express
Styling: CSS
Project Structure
backend/ – Express server and API
frontend/ – React application
screenshots/ – UI images (optional)
How to Run
Start Backend

cd backend
node server.js

Start Frontend

cd frontend
npm run dev

Open in Browser

http://localhost:5173

Key Highlight

This project emphasizes interpreting engineering metrics and providing actionable insights rather than simply displaying raw data.
